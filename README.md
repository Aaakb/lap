# مختبر الأصمعي — نسخة تجريبية

تطبيق Windows لجهاز واحد باستخدام WPF وSQLite و.NET 10. القيم الأولية **مختلقة للتجربة فقط وليست قيماً طبية**؛ يجب إدخال واعتماد قيم المختبر قبل أي استخدام فعلي. هذه النسخة ليست جاهزة لتسجيل مرضى فعليين.

## المتوفر
- إضافة مريض والبحث عنه بالاسم أو الرقم وتعديل بياناته.
- إضافة نطاقات رقمية بحسب العمر بالسنوات والجنس وتعديلها وتعطيلها؛ تمنع النطاقات المتداخلة للتحاليل الفعالة.
- تسجيل نتيجة رقمية أو نصية واحدة في كل مرة مع حفظ نسخة النطاق والاسم والوحدة وبيانات المريض وقت التسجيل.
- إنشاء طلب للمريض وإضافة عدة نتائج إليه، ثم طباعة جميع نتائج الطلب المختار، أو اختيار Microsoft Print to PDF لحفظ التقرير.

## لم يكتمل بعد
إدخال القيم المرجعية المعتمدة من المختبر، والاختبارات التشغيلية النهائية على جهاز المختبر. يجب إنجاز هذه الوظائف ومراجعتها قبل الاستخدام الفعلي.

## التشغيل
افتح MedicalLab.sln في Visual Studio 2026 مع حزمة تطوير تطبيقات سطح المكتب باستخدام .NET، أو نفذ `dotnet run --project MedicalLab`. تُحفظ القاعدة تحت LocalApplicationData/AlAsmaiLab. تنشأ التحاليل التجريبية مرة واحدة عند أول تشغيل فقط. لا تحذف قاعدة موجودة لترقيتها.

اختبارات المطور: `dotnet test MedicalLab.Tests`.

## تجربة الطلبات
أضف مريضاً بتاريخ ميلاد، ثم افتح النتائج والتقارير واختر المريض واضغط إنشاء طلب للمريض. أدخل نتائج التحاليل المطلوبة بالتتابع، ثم اضغط حفظ PDF مباشر أو طباعة الطلب. تبقى بيانات التقارير السابقة محفوظة كما كانت عند تسجيل النتائج حتى بعد تعديل بيانات المريض أو قيم التحاليل.


## الإعدادات والنسخ الاحتياطي
يمكن تعديل اسم المختبر وعنوانه وهاتفه واختيار شعار PNG أو JPEG من تبويب الإعدادات، ثم الضغط على حفظ بيانات المختبر. لإنشاء نسخة احتياطية اختر ملفاً جديداً بامتداد db. قبل الاستعادة يفحص البرنامج نسخة مؤقتة مستقلة ويحدّث بنيتها، ويقرأ جميع الجداول للتحقق من توافق البيانات والشعار قبل استبدال القاعدة الحالية. لا يعدل ملف النسخة المختار. يحفظ نسخة من القاعدة الحالية بجانبها باسم before-restore. قد تحتوي النسخة على بيانات شخصية؛ احفظها في مكان موثوق.

## بناء التنصيب
نفّذ `packaging/Publish.ps1` لبناء نسخة مستقلة ببيئة .NET 10.0.15، ثم `packaging/Build-Msi.ps1` لإنشاء حزمة 0.1.1، أو ترجم packaging/setup.iss باستخدام Inno Setup. يفحص البناء إصدارات المكتبات الفعلية ويرفض تغليف مخرجات قديمة. ملفات البيانات منفصلة عن ملفات البرنامج ولا يحذفها إلغاء التثبيت. يمكن أيضاً بناء MSI بأدوات Windows المدمجة باستخدام packaging/Build-Msi.ps1.


## التحاليل النصية
اختر نوع النتيجة نصية من شاشة التحاليل، وأدخل المرجع مثل Negative، ثم العمر والجنس. لا تحتاج الحدود الرقمية للنوع النصي. يمكن إدخال نتيجة نصية من شاشة النتائج. المقارنة مع المرجع تتجاهل اختلاف الأحرف الإنجليزية الكبيرة والصغيرة؛ لا يفسر البرنامج المرادفات أو المعنى الطبي. إذا تركت المرجع فارغاً تصنف النتيجة وصفية. يحفظ التقرير نسخة المرجع وقت التسجيل.


## الاستخدام الفردي
يفتح البرنامج مباشرة دون تسجيل دخول، ويمنع فتح نسختين في جلسة Windows نفسها. القاعدة محلية وغير مشفرة؛ هذه النسخة معدة لجهاز ومستخدم واحد.

## المجموعات والاعتماد
أضف مجموعة بأسماء تحاليل إنجليزية، كل اسم في سطر. اختر الطلب ثم المجموعة لإضافة تحاليلها. تظهر التحاليل المنتظرة حتى إدخال نتائجها. يمكن إزالة تحليل منتظر من مسودة. الاعتماد يتطلب اكتمال النتائج، ويمنع تعديلها حتى إعادة فتح الطلب للتصحيح. يسجل البرنامج الإضافة والحذف والاعتماد وإعادة الفتح في سجل محلي.

## التقرير
اسم المختبر والمريض بالعربية، وجدول التحاليل والنتائج إنجليزي من اليسار إلى اليمين. زر حفظ PDF مباشر ينشئ تقرير A4 متعدد الصفحات. تحفظ الصفحات كصور عالية الدقة داخل PDF للحفاظ على تشكيل العربية؛ النص داخل PDF غير قابل للتحديد. الطباعة المباشرة متاحة أيضاً.

## بناء حزمة MSI
بعد نشر التطبيق نفّذ packaging/Build-Msi.ps1. الحزمة تثبت ملفات البرنامج للمستخدم الحالي وتضيف اختصارات. تنشأ القاعدة عند أول تشغيل خارج مجلد التنصيب، وتبقى بعد إلغاء التثبيت. اختُبر استخراج الحزمة وتطابق 428 ملفاً، واختُبر تثبيت الحزمة وإلغاء تثبيتها في مجلد اختبار محلي. يظل اختبارها على جهاز مختبر آخر مطلوباً.


## الواجهة
تنقل جانبي وألوان طبية هادئة وخط Segoe UI واضح، مع حقول قابلة للوصول بلوحة المفاتيح. الحد الأدنى للنافذة 900×650 بوحدات Windows المنطقية؛ الجداول تتمرر أفقياً عند الحاجة. أغلق النافذة القديمة ثم شغّل نسخة publish لرؤية آخر التعديلات.

## إصلاحات 0.1.1
للتحليل هوية ثابتة مستقلة عن الاسم. تغيير اسمه في أحد النطاقات يغيّر اسم جميع نطاقاته ويحدّث الطلبات والمجموعات المرتبطة به في معاملة واحدة، بينما تبقى أسماء النتائج السابقة ووحداتها ومراجعها كما سُجلت. لا يُسمح بدمجه ضمناً مع اسم تحليل آخر موجود.

تسمح الطباعة وPDF بإخراج نتائج جزئية، لكن التقرير يوضح أنه جزئي ويسرد التحاليل المنتظرة بالإنجليزية. يستخدم المساران نفس بيانات التقرير المقروءة من القاعدة. تعالج الطباعة أخطاء الشعار والطابعة برسالة واضحة. تُفحص الشعارات أيضاً قبل قبول استعادة قاعدة البيانات.

نجح 61 اختباراً على قواعد وبيانات وهمية، وفُحص تقرير جزئي بصرياً. لم تُجرّب طابعة المختبر الفعلية أو ترقية تثبيت قائم على جهاز آخر. ملفات MSI الأقدم في installer-output أرشيف؛ النسخة الحالية AlAsmaiLab-Setup-0.1.1.msi.
